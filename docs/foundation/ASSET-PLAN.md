# Phase 00 Asset Plan

## Asset principles

- Every asset must support an automotive story.
- Use one consistent dark, high-contrast, metallic/warm visual treatment.
- Prefer original UI mockups and approved product screenshots for proof.
- Use stock photography for atmosphere, not fake proof.
- Do not use YNA assets, logos, screenshots, or imagery.
- Do not use recognizable logos/brands in commercial visuals without permission.
- Save source and license details for every external asset.

## Asset registry fields

Every external or generated asset should have:

```text
filename
usage/page
source URL
creator
download/generation date
license name and URL
attribution requirement
model/property/trademark concerns
approved by
```

## Stock source policy

Use Unsplash, Pexels, and Pixabay where appropriate, after checking the current license and rights for the individual asset. Unsplash and Pexels generally allow commercial website use; Pixabay requires additional care around recognizable trademarks, logos, and brands.

For production, retain a local asset-license record even if attribution is not required.

## Image treatment

- Use darkened/high-contrast crops with room for white overlay text.
- Apply consistent color grading rather than unrelated filters.
- Use page-specific color overlays that harmonize the image with the animated gradient.
- Use `next/image` and optimized WebP/AVIF output where appropriate.
- Provide useful alt text; decorative images must have empty alt text.

## Missing/uncertain assets

If a required CarVu screenshot, metric, logo, or client asset is not approved, use a clearly labeled mockup or abstract interface. Never invent a client result or imply an unauthorized relationship.
