# Phase 00 — Content and Design Foundation

## Goal

Turn the project brain into an approved content map, visual direction, page inventory, asset plan, and route contract before building application features.

## Work

- Finalize positioning and the primary homepage headline.
- Finalize navbar labels and route names.
- Finalize the seven solution categories.
- Define services, case studies, Insights categories, and customer segments.
- Create content outlines for every page type.
- Define copy tone: specific, confident, automotive, practical, and free of generic agency language.
- Define graphite/orange visual tokens and gradient color mapping.
- Define image art direction and asset-license tracking.
- Confirm CarVu content that can be publicly disclosed.
- Define which screenshots are real, anonymized, mockups, or unavailable.
- Define proposal and scheduling copy.

## Acceptance criteria

- Every route has a purpose and target audience.
- Every solution has a detailed content outline.
- Every dynamic detail type has required fields.
- No broad unrelated industries remain.
- Homepage sequence is approved.
- Header/menu behavior is approved.
- Asset plan has no unlicensed or ambiguous images.

## Test

Review the content map as a nontechnical automotive prospect. Confirm that a dealership, fleet operator, service center, parts business, marketplace, auction company, and custom-software buyer can identify the correct path.
